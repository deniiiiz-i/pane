# Pane

Liquid glass components for React.

Pane recreates Apple's liquid glass material as a shadcn registry: a refracted
rim, a tinted backdrop and a specular highlight that follows the pointer. It
ships as source you own, not as an npm package — the CLI copies the files into
your project.

**[pane.theui.company](https://pane.theui.company)**

## Installation

Add a component directly from the registry:

| Component | Description | Install |
| --- | --- | --- |
| [Pane](https://pane.theui.company/docs/components/pane) | The base liquid glass surface. | `npx shadcn@latest add @pane/pane` |
| [Button](https://pane.theui.company/docs/components/button) | A glass button with default and destructive variants. | `npx shadcn@latest add @pane/button` |
| [Card](https://pane.theui.company/docs/components/card) | A glass panel with header, content and footer slots. | `npx shadcn@latest add @pane/card` |
| [Badge](https://pane.theui.company/docs/components/badge) | A compact glass badge for labels and statuses. | `npx shadcn@latest add @pane/badge` |
| [Input](https://pane.theui.company/docs/components/input) | A text input rendered on a glass surface. | `npx shadcn@latest add @pane/input` |
| [Switch](https://pane.theui.company/docs/components/switch) | A toggle with a spring animated glass thumb. | `npx shadcn@latest add @pane/switch` |
| [Tabs](https://pane.theui.company/docs/components/tabs) | Tabs with a sliding glass indicator. | `npx shadcn@latest add @pane/tabs` |
| [Tooltip](https://pane.theui.company/docs/components/tooltip) | A glass popover for contextual hints. | `npx shadcn@latest add @pane/tooltip` |
| [Dialog](https://pane.theui.company/docs/components/dialog) | A modal glass panel over a blurred overlay. | `npx shadcn@latest add @pane/dialog` |
| [Sheet](https://pane.theui.company/docs/components/sheet) | A glass panel that slides in from any side. | `npx shadcn@latest add @pane/sheet` |
| [Popover](https://pane.theui.company/docs/components/popover) | A floating glass panel anchored to a trigger. | `npx shadcn@latest add @pane/popover` |
| [Dropdown Menu](https://pane.theui.company/docs/components/dropdown-menu) | A glass menu with checkbox and radio items, shortcuts and submenus. | `npx shadcn@latest add @pane/dropdown-menu` |
| [Select](https://pane.theui.company/docs/components/select) | A glass field that opens a glass list of options. | `npx shadcn@latest add @pane/select` |
| [Slider](https://pane.theui.company/docs/components/slider) | A glass track with a knob that turns to glass while dragged. | `npx shadcn@latest add @pane/slider` |
| [Toggle Group](https://pane.theui.company/docs/components/toggle-group) | A single-choice control with a sliding glass indicator. | `npx shadcn@latest add @pane/toggle-group` |
